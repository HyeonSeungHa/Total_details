# Total_details

차량 음원 정제 작업과 처리 결과 집계를 Streamlit 화면으로 구현한 내부 업무 도구 프로토타입입니다.

## 프로젝트 배경

기존 **PyQt5 기반 AuRRA**를 웹 환경에서도 사용할 수 있는지 검토하기 위해 일부 기능을 Streamlit으로 옮겨 테스트했습니다. 따라서 `pages/1_AuRRA_streamlit.py`는 AuRRA의 정식 웹 버전이나 전체 재구현본이 아니라, 다음 핵심 흐름의 웹 전환 가능성을 확인한 **PoC(Proof of Concept)** 입니다.

1. DB에서 음원 정제 대상 조회
2. 원본 WAV 다운로드 및 파형·스펙트로그램 확인
3. 시작 지점을 기준으로 4초 구간 추출
4. 추출 음원 업로드 및 후처리 API 호출
5. 특징값·이미지·영상 생성 결과를 DB에 반영
6. 작업 완료 결과를 외부 API로 전달

함께 포함된 두 집계 페이지는 AuRRA 작업 결과를 날짜별로 확인하고 엑셀로 내려받기 위한 보조 도구입니다.

> 현재 저장소의 DB 계정과 사내 API 주소는 설명용 문자열로 대체되어 있습니다. 실제 연동 정보와 대상 DB 스키마가 없으면 화면의 전체 기능을 실행할 수 없습니다.

## 주요 화면

| 파일 | 역할 | 주요 기능 |
| --- | --- | --- |
| `Hello.py` | Streamlit 진입점 | 멀티페이지 앱 실행 및 페이지 탐색(현재 기본 예제 화면) |
| `pages/1_AuRRA_streamlit.py` | AuRRA 웹 전환 PoC | 대상 조회, 음원 재생, 파형·스펙트로그램 표시, 4초 구간 편집, 파일 업로드, 후처리 API 호출, DB 반영 |
| `pages/2_tally_noise.py` | 노이즈 처리 집계 | 날짜 범위별 처리 상태·노이즈 유형 집계, 상세 데이터 확인, 엑셀 다운로드 |

## AuRRA Streamlit 처리 흐름

`pages/1_AuRRA_streamlit.py`는 화면을 `조회`, `원본`, `편집`, `DB적재` 탭으로 나눕니다.

- **조회**: 고객 요청과 음원 정제 상태를 DB에서 조회하고 작업 대상을 선택합니다.
- **원본**: 파일 관리 서버에서 WAV를 내려받아 재생하고 파형과 주파수 스펙트로그램을 표시합니다.
- **편집**: 입력한 시작 시점부터 4초 길이의 음원을 추출해 미리 확인합니다.
- **DB적재**: 추출 음원의 특징값, 스펙트로그램 PNG, 주파수 이미지, MP4 생성을 후처리 API에 요청하고 파일 GID와 분석 결과를 DB에 저장합니다.

코드에는 개발/운영 환경 선택 UI가 있지만, 두 환경의 실제 접속 설정은 모두 비식별화되어 있습니다.

## 집계 기능

### 노이즈 처리 집계

선택한 날짜 구간의 음원 처리 데이터를 조회해 정상 처리, 원본 없음, 4초 미만, 노이즈, 기타 오류, 미진행 등의 상태를 일자별로 집계합니다. 결과는 다음 시트가 포함된 엑셀 파일로 내려받을 수 있습니다.

- 총 집계
- 노이즈 정상 처리 집계
- 노이즈 데이터 세부 정보

### 보고서 생성 결과 집계

선택한 날짜 구간의 자동·수동 음원 정제 결과와 보고서 생성 데이터를 집계합니다. 일자별 집계와 차량별 보고서 상세 내역을 화면에서 확인하고 엑셀로 내려받을 수 있습니다.

## 기술 구성

- Python
- Streamlit 1.13
- Pandas / NumPy
- Librosa / SoundFile / Matplotlib
- PyMySQL
- Requests
- OpenPyXL

`requirements.txt`는 개발 당시 버전으로 고정되어 있습니다. NumPy, Numba, Streamlit 등 패키지 버전이 오래되었으므로 최신 Python보다 Python 3.9~3.10 계열의 별도 가상환경 사용을 권장합니다.

집계 페이지에서 사용하는 `openpyxl`은 현재 `requirements.txt`에 선언되어 있지 않습니다. 실행 시 별도로 설치해야 하며, 환경을 다시 정비할 때 검증된 버전을 `requirements.txt`에 추가하는 것이 좋습니다.

## 실행 전 준비

다음 외부 자원과 설정이 필요합니다.

- MySQL 호환 DB와 대상 업무 테이블
- 음원 다운로드·업로드가 가능한 파일 관리 서버
- 특징값, 이미지, 영상 생성을 수행하는 음원 후처리 API
- 작업 완료 결과를 수신하는 API
- 한글 그래프 출력을 위한 `NanumGothic` 글꼴

현재 소스의 아래 설명용 값을 실제 환경 설정으로 교체해야 합니다.

- `DB접속 주소`, `사용자`, `비밀번호`, `DB`
- `음원파일을 다운 받는 주소`
- `음원 편집 후 후처리 API 주소`
- `작업 완료 후 보내는 주소`

운영 목적으로 사용할 때는 값을 코드에 직접 입력하지 말고 Streamlit Secrets 또는 환경 변수로 분리해야 합니다.

## 로컬 실행

```bash
python -m venv .venv
```

Windows PowerShell에서 가상환경을 활성화하고 의존성을 설치합니다.

```powershell
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
pip install openpyxl
streamlit run Hello.py
```

실행 후 브라우저의 사이드바에서 각 페이지를 선택합니다. AuRRA 페이지가 내려받거나 생성한 임시 파일은 프로젝트 루트의 `file_dir/`에 저장됩니다.

## 현재 상태와 제약

이 저장소는 개발 당시의 웹 전환 실험과 집계 로직을 보관한 코드입니다. 재사용하거나 운영 환경에 배포하려면 다음 항목을 먼저 보완해야 합니다.

- DB·API 설정을 소스 코드에서 분리하고 개발/운영 환경별로 관리
- 쿼리 문자열 보간을 파라미터 바인딩 방식으로 변경
- API 폴링에 타임아웃, 실패 처리, 재시도 정책 추가
- Streamlit 세션 상태를 사용해 페이지 재실행 시 작업 상태 보존
- DB 연결과 파일 핸들을 컨텍스트 매니저로 관리
- 동시 사용자별 임시 파일 경로 분리 및 작업 후 정리
- 기본 예제인 `Hello.py`를 프로젝트 안내 화면으로 교체
- 단위 테스트, 연동 테스트, 샘플 또는 목 데이터 추가
- 오래된 의존성 업그레이드 후 음원 처리 결과와 엑셀 출력 회귀 검증

특히 이 PoC는 DB 갱신과 외부 API 호출을 포함하므로, 실제 운영 데이터에 연결하기 전에 격리된 개발 환경에서 먼저 검증해야 합니다.
